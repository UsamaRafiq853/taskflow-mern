**TaskFlow - Task Management System**

TaskFlow is a web-based task management application developed as part of my B9IS130 Web Development module using the MERN Stack.
The application will allow users to manage tasks, set priorities, track deadlines, and monitor progress with secure user authentication.

Technologies:

Frontend: React.js (Planned)
Backend: Node.js, Express.js
Database: MongoDB Atlas, Mongoose
Language: JavaScript
Validation: Zod
Version Control: Git & GitHub

Work Completed:

- Set up GitHub repository and project structure.
- Created Express.js backend and health API.
- Connected MongoDB Atlas.
- Created User and Task database models.
- Implemented API error handling.
- Started input validation using Zod.

Upcoming Features:

- User registration and login
- JWT authentication and password hashing
- Role-based access control (Admin/User)
- Task management (CRUD)
-React dashboard
